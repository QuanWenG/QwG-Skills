# 外观模式

## 摘要

外观模式为复杂子系统提供一个统一、简洁的高层接口，使客户端更容易使用子系统。

它不一定隐藏所有细节，也不禁止客户端直接访问子系统；它只是为常用流程提供更稳定的入口。

## 解决的问题

客户端为了完成一个用例，需要按顺序调用多个子系统。调用散落在各处会重复、易错，也让客户端了解过多内部流程。外观对象把流程收拢。

## 核心思想

Facade 持有或调用多个子系统，把复杂调用组合成一个或少数几个高层方法。

## 结构与角色

- Facade：统一入口。
- Subsystem：复杂子系统。
- Client：调用 Facade。

## 适用场景

- 子系统复杂，常用流程固定。
- 需要降低客户端接入成本。
- 需要为旧系统提供新入口。
- 分层架构中对外暴露应用服务。

## 不适用场景

- Facade 变成上帝对象，聚合所有功能。
- 客户端需要大量细粒度控制。
- 子系统本身已经足够简单。

## 多语言实现

### Java

```java
final class Inventory { boolean reserve(String sku) { return true; } }
final class Payment { void pay(int cents) {} }
final class Shipping { void ship(String sku) {} }

final class OrderFacade {
    private final Inventory inventory = new Inventory();
    private final Payment payment = new Payment();
    private final Shipping shipping = new Shipping();

    void placeOrder(String sku, int cents) {
        if (inventory.reserve(sku)) {
            payment.pay(cents);
            shipping.ship(sku);
        }
    }
}
```

### Python

```python
class GameDailyFacade:
    def __init__(self, stamina, base, friends) -> None:
        self._stamina = stamina
        self._base = base
        self._friends = friends

    def run_daily_tasks(self) -> None:
        self._stamina.clear()
        self._base.rotate()
        self._friends.visit()
```


### TypeScript

```ts
class VideoFacade {
  async export(input: string): Promise<string> {
    const decoded = await this.decode(input);
    const encoded = await this.encode(decoded);
    return this.upload(encoded);
  }

  private async decode(input: string) { return input; }
  private async encode(input: string) { return input; }
  private async upload(input: string) { return input; }
}
```

## 优点

- 简化客户端调用。
- 统一复杂流程。
- 降低子系统耦合暴露。

## 代价与风险

- Facade 容易膨胀。
- 过度隐藏会限制高级用法。
- 子系统异常处理要设计清楚。

## 常见误区

- 误区：外观必须封死子系统。
  正解：它提供便利入口，不必禁止高级客户端直接使用子系统。
- 误区：外观就是工具类。
  正解：外观表达一个子系统边界或用例入口。

## 和其他模式的关系

- 适配器转换接口，外观简化接口。
- 中介者协调同级对象，外观面向客户端隐藏子系统。
- 迪米特法则常通过外观落地。

## 检查清单

- 客户端是否重复调用一串子系统？
- 是否有稳定高层用例可以封装？
- Facade 是否开始承担太多业务？
- 是否仍允许必要的细粒度访问？
